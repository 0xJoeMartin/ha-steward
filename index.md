# Steward

**A proactive caretaker for Home Assistant.**

Steward is a self-hosted Home Assistant add-on. It:

- **Watches** the home: device health, batteries, integrations, network devices, cameras.
- **Learns** by running small, time-boxed experiments (for example, whether a camera can tell a cover is open)
  and turning the ones that work into sensors.
- **Proposes** changes (automations, sensors, ignore rules) with the evidence behind them.
- **Asks first.** Nothing changes until the owner approves it from their phone, the Home Assistant dashboard or
  by voice, and every change can be undone.
- **Briefs** the household morning and evening on what matters today.

## Status

Early development. Steward runs privately in a single home; the add-on is not yet published.
